THE THING BEHIND YOU

A small 2D horror game made in Godot

How to play:
  - Collect all the fuses to unlock the exit and escape
  - pickup batteries to refill the flashlight
  - escape form the ghost that is chasing you

How to run:
  1. Download the ZIP file form releases
  2. extract and run the .exe
  3. for Linux might have to run chmod before running the .sh file
